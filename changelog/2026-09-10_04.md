## Why care?

The theme of the day is holding: **the expensive bugs are the quiet ones.**

Yesterday's memo pipeline had an agent that never produced a table and said
nothing about it. Today it had a closed-corpus enforcement mode that switched
itself off whenever the operator ran without an API key — which is the
configuration this whole refactor exists to make possible.

None of these were found by looking for them. They were found because routing an
agent to a different provider means reading it end to end, and reading it means
noticing what it actually does rather than what its name says.

## What changed

**The writer and all three researchers now route through `llm_provider`** —
`writer.py`, `researcher.py`, `research_enhanced.py`,
`codified_section_researcher.py`. Direct-client call sites: **10 across 9
modules**, down from 23 across 19 at the start of the day.

**`complete_with_retry()` replaces three hand-rolled retry loops.** Two lived in
the writer, one in the scorecard evaluator, and all three wrapped `model.invoke`
in `except (InternalServerError, RateLimitError)`. That shape is a trap the
moment an agent is routed: `complete()` reports provider failures on the
response rather than raising, so the except clause stops matching and **the
retry becomes dead code without anyone editing it**. The shared helper keys on
`.ok`, which also covers the failures the exception list never named — a CLI
timeout, a non-zero exit, a completion that comes back empty.

It returns the last failed response rather than raising, because callers differ
on what giving up means: the writer falls back to unpolished research, the
scorecard emits a neutral score. Forcing an exception would take that choice
away. `tests/test_llm_retry.py` pins that contract, plus the exponential
backoff and the fact that `attempts=1` means one call rather than one call plus
a retry.

## Codified mode was switching itself off

`codified_section_researcher.py`, one line:

```python
use_llm = bool(os.environ.get("ANTHROPIC_API_KEY")) and sources_md.mode == "codified"
```

With a Claude Code seat available and no API key set, `use_llm` is False, and
synthesis silently falls through to `_synthesize_raw` — a raw dump of the
curated sources instead of a researched, cited, grounding-verified section.

The memo still generates. The research files still appear. They are simply not
what codified mode promises, and nothing in the run says so. It now asks whether
*a* provider is reachable:

```python
provider_available = cli_available() or bool(os.environ.get("ANTHROPIC_API_KEY"))
```

The same guard, in a milder form, was on all five agents in the previous entry
and both remaining researchers here: four of them raised `ValueError` when the
key was missing. On a CLI-first pipeline that refuses to start precisely when
the seat would have carried the run.

## The re-prompt that could not see the draft

The codified researcher validates its own output — every source must be cited,
every quoted figure must appear in the source it is attributed to — and
re-prompts when validation fails. The re-prompt was:

```python
retry = llm.invoke([
    SystemMessage(content=system_prompt),
    HumanMessage(content=user_prompt),
    *( [] ),                                 # <- the draft belonged here
    HumanMessage(content="Your draft failed validation… "
                         "Keep everything that was correct."),
])
```

`*([])` splats an empty list. The assistant turn was never there. So the model
was told to keep everything correct about a draft **it was not shown**, and had
to regenerate from scratch each time — which is why the accept-only-if-better
check downstream so often had nothing better to accept.

This is the same defect the `amend` directive had two entries ago: *the minimum
change is not followable without the thing being changed.* Folding the
conversation into a single prompt made the omission unavoidable to see, and the
prior draft now travels in the correction.

## The closed-corpus rule survives the fold

These agents passed a `SystemMessage` and a `HumanMessage`. The CLI path
replaces the system prompt with its own extraction preamble, so anything
load-bearing in the system role gets honoured on the API and dropped on the
seat. For `research_enhanced` and the codified researcher that role carried the
anti-fabrication constraint itself.

Folding it into the body is the fix; the question is whether it still binds.
Tested against the seat with two tiny sources and a question they do not answer:

```
ok=True  provider=cli

Blinka raised a $2.4M seed extension in November 2024.[^1]
As of Q3 2025, the company's ARR reached $410,000.[^2]

**(b) Blinka's CEO — name and prior employer**
<insufficient-data field="ceo_name"/>
<insufficient-data field="ceo_prior_employer"/>
```

Both sources cited, and a marker rather than an invented CEO — `AGENTS.md` §5
and §7 holding on the folded prompt.
