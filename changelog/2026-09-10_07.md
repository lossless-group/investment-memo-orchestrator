## Why care?

Twenty-eight modules route through the CLI-first provider. Six changelog entries
today have been counting the number down from twenty-four call sites to one.

And until this entry, `python -m src.main` opened with:

```python
if not os.getenv("ANTHROPIC_API_KEY"):
    console.print("[bold red]Error:[/bold red] ANTHROPIC_API_KEY not set in environment")
    sys.exit(1)
```

**The front door refused to open.** Every agent could route to a subscription
seat and it would not have mattered — the pipeline exits 1 before parsing its
own arguments. A whole day of refactoring, gated behind four lines nobody
looked at because they had been correct since the day they were written and
nothing about them changed.

That is the shape of every find in this refactor, stated plainly: **these guards
were all correct when an API key was the only way to reach a model. None of them
were revisited when that stopped being true.** The fact-checker's corrections,
codified mode's synthesis, the one-pager, five `ValueError`s — and finally the
entry point itself.

It now asks whether *any* provider is reachable, and says which one is about to
be billed before anything is:

```
LLM provider: Claude Code CLI (subscription seat), metered API as fallback
```

## What changed

**Three agents routed.** `one_pager_generator` (two calls — slot extraction, then
HTML layout per mode), `scorecard_agent`, `portfolio_listing_agent`.

The one-pager carried the same silent skip the fact corrector did: no key meant
the memo shipped without its cover sheet and the reason scrolled past in a long
log. Now gated on provider reachability.

`portfolio_listing_agent`'s system prompt defines the `JSON:` / `MARKDOWN:` split
its own parser depends on, so it folds into the body like the others — the CLI
path substitutes the system role, and a dropped format contract would have
produced an unparseable reply rather than a loud failure.

Verified on the seat, end to end through the real parser:

```
elapsed=7.6s ok=True provider=cli
parsed: {'company': 'Blinka',
         'one_liner': 'making commercial real estate lending automatic with AI agents',
         'ask': '$5M seed at a $28M pre-money valuation',
         'stage': 'seed'}
```

**The generated reference learned to count to one.** With the inventory down to a
single module it began reading `1 modules / 1 call sites`, and it now pluralises
— including the sentence it will print when the last one lands.

## Suite

**434 passed, 1 skipped.**

## What is still open

`src/server/brand_fetch.py`, one call site. It runs inside the FastAPI sidecar
rather than the graph, and the honest reason it is last is that nobody has shown
the `claude` CLI is reachable from that process. Finding out during a live memo
run is the wrong way to learn it, so that one gets a deliberate check first.
