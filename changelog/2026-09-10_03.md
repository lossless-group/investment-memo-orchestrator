```
feat(llm): route the five single-call agents through the CLI-first provider
fix(tables): prose detection raised KeyError on its own JSON example, always
test(prompts): fail when a .format()ed prompt cannot render its own braces
fix(scorecard): retry on .ok, not on exceptions the provider no longer raises

Reading five agents closely enough to route them surfaced one that had never
worked. detect_prose_tables called .format() on a prompt containing a JSON
example; the single braces were replacement fields, so every call raised
KeyError, hit a bare except, and printed a warning indistinguishable from "no
tabular data found". Direct-client call sites are now 14 across 13 modules,
down from 24 across 19.
```

## Why care?

A silent failure is worse than a loud one, and this repo just found a four-month
example of the worst kind: an agent that ran on every memo, cost nothing,
produced nothing, and said so in language that read like success.

The tell was never going to come from review. The prompt reads fine. The call
reads fine. Only their combination fails, and the failure was caught by a bare
`except Exception` that printed `Warning: Prose detection failed for {section}`
— which is exactly what a section with no tabular data would also print.

We found it because routing an agent to a different provider means reading it,
and reading it means running it.

## What changed

**Five agents now route through `llm_provider`** — `validator`,
`scorecard_evaluator`, `table_generator`, `link_enrichment`,
`visualization_enrichment`. Combined with the deck analyst, direct-client call
sites are down to **14 across 13 modules**, from 23 across 19 at the start of the
day.

**Every one of them required `ANTHROPIC_API_KEY` to be set**, four of them
raising `ValueError` if it was missing. On a CLI-first pipeline that guard is
backwards: it refuses to start precisely when the seat would have carried the
run. All five guards are gone.

**System prompts fold into the body.** These agents passed a `SystemMessage` and
a `HumanMessage`. The CLI path replaces the system prompt with its own extraction
preamble, so anything load-bearing there — the validator's scoring schema, the
link enricher's rules — would have been dropped on one provider and honoured on
the other. Folding it into the prompt makes both providers see the same thing.

**The scorecard's retry now keys on `.ok`.** It caught `InternalServerError` and
`RateLimitError` from `anthropic`. `complete()` never raises for a provider
failure — it returns a response with `.ok` false — so an exception-keyed retry
would have quietly become dead code that stopped retrying anything. Keying on
`.ok` also covers what the exception list never named: a CLI timeout, a non-zero
exit, an empty completion.

## The table detector that never detected a table

`PROSE_DETECTION_PROMPT` ends with a JSON example:

```
Return JSON:
{
    "tables": [ ... ]
}

SECTION CONTENT:
---
{content}
---
```

and the call site was `PROSE_DETECTION_PROMPT.format(content=content)`.

To `str.format`, `{` opens a replacement field. The first one it meets is
`{\n    "tables"`, so every call raised `KeyError('\n    "tables"')` before a
single token reached a model. The `except Exception as e` around it caught the
error, printed a warning, and returned `[]`.

Confirmed against `HEAD` rather than assumed — the committed version raises the
same `KeyError`. **Prose-table detection has never once produced a table.**

The fix is `.replace("{content}", content)`, not escaped braces. Doubling twelve
braces works until the next person edits the JSON example, which is how this
arrived. `.replace` cannot be broken that way.

Working, on the first try after the fix:

```
elapsed=18.1s  tables detected=1
  type: funding_rounds  columns: ['Round', 'Date', 'Amount Raised', 'Valuation', 'Lead Investors']
    {'Round': 'Pre-seed', 'Date': 'March 2023', 'Amount Raised': '$750,000', ...}
    {'Round': 'Seed Extension', 'Date': 'November 2024', 'Amount Raised': '$2.4M', ...}
    {'Round': 'Seed', 'Date': 'In progress', 'Amount Raised': '$1.8M committed / $5M target', ...}
```

## Tested rather than reviewed

A bug invisible to inspection does not get fixed by promising to look harder.
`tests/test_prompt_templates.py` walks every module-level string constant in
`src/` that is `.format()`ed anywhere, renders it with the keywords its own call
site passes, and fails if it raises. It is the general form of the bug, not a
guard on the one instance.

The sweep found no other offender — so the JSON-example hazard is closed rather
than merely catalogued. Reverting the fix makes two tests go red, which we
checked rather than assumed.

Suite at **426 passed, 1 skipped**.

## What is still open

Nine modules and ten call sites remain: the writer, both researchers, the
correctors, `one_pager_generator` (2), `scorecard_agent`, `source_extractor`,
`portfolio_listing_agent`, and `brand_fetch.py` — which goes last, because it
runs inside the FastAPI sidecar and the CLI has to be shown reachable from there
first.

`KNOWN_BYPASSING` in `tests/test_pipeline_reference.py` is the ratchet. Routing
a module means striking its line, and the suite fails if you forget.
